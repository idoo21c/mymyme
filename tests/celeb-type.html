유명인 마마미 — 나와 같은 유형의 유명인은?

MyMyMe 유명인 마마미는 국내·해외 유명인 231명 중 나와 사주 일간이 같은 사람, MBTI가 같은 사람, 둘 다 같은 사람을 보여 주는 무료 비교예요. 생년월일은 공개된 프로필, MBTI는 본인이 방송·인터뷰·SNS에서 직접 밝힌 것만 써요.

무엇을 알 수 있나요?

  • 나와 사주 일간이 같은 유명인
  • 나와 MBTI가 같은 유명인(본인이 밝힌 경우만)
  • 일간과 MBTI가 모두 같은 '똑같은 유형'
  • 국내·해외로 나눠 보기

어떻게 하나요?

  1. 내 일간 알기 · 생년월일만 넣으면 30초 만에 일간이 나와요.
  2. 성향까지 · 82문항 사주 × 성향을 하면 MBTI가 같은 유명인도 찾아요.
  3. 비교·공유 · 결과로 오늘의 한마디를 남기거나 친구에게 공유해요.

자주 묻는 질문

유명인 MBTI는 어디서 가져오나요?

본인이 방송·인터뷰·SNS에서 직접 밝힌 것만 쓰고 출처를 함께 보여 줘요. 추측이나 '~로 알려진' 정보는 쓰지 않아요.

유명인 사주는 정확한가요?

공개된 생년월일로 계산한 일간이에요. 태어난 시간은 공개되지 않아 년·월·일까지만 봐요.

정치인도 있나요?

현역 정치인은 넣지 않아요. 사진도 쓰지 않아요.
